## 👨‍💻 Sobre Mí
Profesional con experiencia en el desarrollo y validación de aplicativos informáticos para la industria farmacéutica y biotecnológica. Especializado en programación orientada a la automatización documental y analítica bajo lineamientos GAMP5. 

* **Visión Técnica:** Diseño de sistemas, estructuración de lógica de procesos y optimización de flujos de trabajo.
* **Soluciones:** Creación de soluciones digitales a medida, escalando desde herramientas de macros y bases de datos relacionales, hasta arquitecturas y desarrollos web.
* **Aporte de Valor:** Alta orientación al detalle y pensamiento estructurado para crear código eficiente y auditable.
